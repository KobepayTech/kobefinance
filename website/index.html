FAQ

A few common questions.

Which markets are covered?

Every major African exchange (JSE, NGX, NSE, EGX, CSE, BRVM, GSE and more), US (NASDAQ/NYSE), UK (LSE), Korea/Taiwan, plus spot forex and crypto. Live quotes come from public feeds; some emerging-market names use a simulated feed where no free real-time data exists.

Is my trading real money?

No — trading defaults to a safe paper broker. Live forex requires connecting your own MetaTrader 5 terminal and broker account, and every live order asks for explicit confirmation.

Do I need an internet connection or API keys?

The app runs offline with a simulated feed and a local-LLM option. Live quotes, fundamentals and news use free public endpoints; no API keys required for the basics.

Is it open source?

The desktop app is developed in the open on GitHub. See the repository for licensing details.
